# 名刺スキャン Skill

Google Drive の指定フォルダにある名刺画像を読み取り、構造化データとして
CSVファイルに追記するための手順書。

## 出力CSVの仕様

ヘッダー行（CSV新規作成時は必ずこの順序・列名で作成する）:



```
処理日時,名刺画像ファイル名,氏名,会社名,部署役職,メールアドレス,電話番号,ステータス,交流場所,交換日,紹介者
```



各列の入力ルール:

- 処理日時: 処理を実行した日時。`YYYY-MM-DD HH:MM` 形式。
- 名刺画像ファイル名: 読み取った画像のファイル名。重複処理の判定キーになる。
- 氏名: 名刺記載の氏名。姓名の間は半角スペース。
- 会社名: 正式名称。「株式会社」等の法人格も省略せず記載。
- 部署役職: 部署名と役職。両方ある場合は「営業部 課長」のように半角スペース区切り。
- メールアドレス: 名刺記載のメールアドレス。
- 電話番号: 代表電話ではなく本人の番号を優先。複数あれば携帯を優先。
- ステータス: 新規追記時は「未処理」。判読に不安がある場合は「要確認」。
- 交流場所 / 交換日 / 紹介者: 処理時は必ず空欄。利用者が後から手動入力する。

## 抽出ルール

- 1枚の画像から1名分を抽出する。両面名刺の場合、情報量の多い面を主とする。
- 項目が名刺に存在しない場合、その列は空欄にする（推測で埋めない）。
- 会社ロゴ周辺の装飾文字や、キャッチコピーは抽出対象外。
- 英語表記と日本語表記が併記されている場合、日本語表記を優先する。
- 役職の英語表記しかない場合はそのまま英語で記載する。

## 誤読対策

メールアドレスは誤読が起きやすい。以下の文字ペアは特に注意する:

- 小文字エル `l` と 数字 `1` と 大文字アイ `I`
- 小文字オー `o` と 数字 `0`
- アンダースコア `_` と ハイフン `-`
- ピリオド `.` と カンマ `,`

判読に確信が持てない場合、無理に確定させず「ステータス」列を「要確認」とし、
後工程（人間の確認）に委ねる。

## 重複処理の防止

CSVの「名刺画像ファイル名」列に既出のファイル名は再処理しない。
照合はファイル名の完全一致で行う。

## やらないこと

- このSkillはCSVへの書き出しまでが責務。
- Gmailの下書き作成・送信は行わない（後続の別工程が担当）。
- CSV既存行の上書き・削除・並べ替えは行わない。追記のみ。
