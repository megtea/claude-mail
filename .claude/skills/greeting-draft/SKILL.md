# 挨拶メール下書き作成 Skill

名刺スキャンSkill（business-card-scan）が出力したCSVを読み込み、
まだ下書きを作成していない相手に対して、Gmailの下書きを作成する手順書。

## 【設定】※提供先はこのブロックのみ書き換える

- 入力CSVファイル名: customer_list.csv
- メールテンプレート: templates/greeting.md
- 1回の実行で作成する下書きの最大件数: 20

## 処理手順

1. 設定の入力CSVを読み込む。
2. 各行の「ステータス」列を確認し、「未処理」の行だけを対象とする。
   「下書き済」「送信済」「要確認」の行はスキップする。
3. 「メールアドレス」列が空欄の行はスキップし、報告に含める。
4. 対象行ごとに、templates/greeting.md のテンプレートの差し込み項目を
   CSVの値で置き換え、Gmailの下書きを1件作成する。
5. 下書き作成に成功した行は、CSVの「ステータス」列を「下書き済」に更新する。
6. 1回の実行で作成する件数は設定の上限を超えない。超える分は次回に回す。
7. 完了後、結果を要約して報告する（下書き作成件数、スキップ件数とその理由）。

## テンプレートの差し込み項目

templates/greeting.md 内の `{{ }}` で囲まれた箇所をCSVの値に置き換える。

- `{{氏名}}` … CSVの「氏名」列
- 宛先メールアドレス … CSVの「メールアドレス」列
- 件名 … templates/greeting.md の先頭で定義された件名を使用

## 厳守事項

- 作成するのは「下書き」のみ。メールの送信は絶対に行わない。
- 「ステータス」が「未処理」以外の行には下書きを作らない（二重作成の防止）。
- CSVの更新は「ステータス」列のみ。他の列・他の行は変更しない。
- メールアドレスが空欄、または「ステータス」が「要確認」の行は
  人間の確認が必要なため下書きを作らず、報告に含める。

## やらないこと

- 名刺画像の読み取り（business-card-scan Skill が担当）。
- メールの送信、送信予約（後続のGAS工程が担当）。
